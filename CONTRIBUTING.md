# Contributing

1. Create a branch from `main`.
2. Make the smallest change that solves the issue.
3. Add or update a focused test and documentation.
4. Run backend tests, the frontend build, and relevant Docker checks.
5. Open a pull request describing behavior, verification, and any provider or
   license considerations.

The project is intentionally local-first. New providers should implement the
existing normalized contracts and keep credentials out of logs and artifacts.
